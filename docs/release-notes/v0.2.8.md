Safer sign-in, fewer crash loops, and the first launch test that really reaches the title screen.

- **Your sign-in is encrypted.** The launcher seals your Minecraft and Microsoft sign-in with Windows' own protection, so another program can't read it from the settings file. Your account carries over; nothing to do.
- **No more crash loops.** If the game crashes shortly after starting, the next launch opens the menus instead of joining the server again.
- **Better memory defaults.** The launcher warns when the game has less memory than Romanica recommends, and never defaults to more than your PC can spare.
- **Clear error when Java can't start,** instead of hanging at "Starting Minecraft".
- **Romanica Client 0.2.0-beta.27:** encrypted sign-in, a plain Fabric client brand on other servers, Romanica features only on Romanica, plus fixes for a singleplayer crash and the minimap.
